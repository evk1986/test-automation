# Runbook: Implement Data Enrichment for Cisco IOS-XR NCS Devices
## Introduction
This runbook covers the implementation of data enrichment for Cisco IOS-XR NCS devices using the NETCONF handler.
## Prerequisites
* NETCONF handler is implemented and tested
* Data Enrichment service is implemented and tested
## Steps
1. Integrate the Data Enrichment service with the NETCONF handler
2. Test data enrichment for a sample NormalizedRecord
3. Test idempotence of data enrichment
