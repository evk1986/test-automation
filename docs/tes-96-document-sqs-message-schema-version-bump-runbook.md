# SQS Message Schema Version Bump Runbook
## Introduction
This runbook documents the process for bumping the SQS message schema version for the Data-Enricher service.
## Prerequisites
* The Data-Enricher service is deployed and running.
* The SQS message schema version needs to be updated.
## Steps
1. Update the SQS message schema version in the Data-Enricher service.
2. Deploy the updated Data-Enricher service.
3. Verify that the SQS message schema version has been updated successfully.
## Verification
* Check the SQS message schema version in the Data-Enricher service.
* Verify that the updated schema version is being used by the service.
