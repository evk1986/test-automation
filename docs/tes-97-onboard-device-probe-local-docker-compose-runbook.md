# Runbook: Onboard Device-Probe Local Docker-Compose Environment
## Introduction
This runbook provides step-by-step instructions for onboarding the Device-Probe local docker-compose environment.

## Prerequisites
* Device-Probe service is installed and configured
* Local docker-compose environment is set up

## Steps
1. Start the Device-Probe service
2. Run the docker-compose up command to start the local environment
3. Verify that the environment is successfully onboarded
